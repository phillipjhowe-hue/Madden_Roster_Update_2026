# Madden NFL 2005 — 2026 Roster Update

A 2026 NFL roster for **Madden NFL 2005 on PS2**, with current teams, rookies, real depth charts and Madden NFL 27 ratings. See [CHANGELOG.md](CHANGELOG.md) for everything that changed.

## Install (PCSX2)

1. Download `Madden05-2026-Roster.zip`.
2. In PCSX2, open **Settings → Memory Cards** and make sure Slot 1 uses a **Folder** memory card (create one if yours is a `.ps2` file).
3. Click **Open Memory Card Directory** and open your folder card (e.g. `Mcd001.ps2`).
4. Extract the `BASLUS-21000D2026` folder from the zip into it.
5. Boot Madden NFL 2005 and go to **My Madden → Load**, then pick *Roster 2026*.

For a real PS2, copy the `BASLUS-21000D2026` save to a memory card with a save manager (e.g. uLaunchELF).
